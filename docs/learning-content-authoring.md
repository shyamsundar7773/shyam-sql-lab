# Learning content authoring

## Sources

- `src/data/learningPath/taxonomy.json` is the single official Category → Topic → Subtopic taxonomy. Content imports cannot add or rename taxonomy nodes.
- `src/data/learningPath/content/txt/` contains finalized plain-text source lessons.
- `src/data/learningPath/content/approved-content.generated.json` is generated by the importer; do not edit it by hand.
- `src/data/learningPath/content/legacy-content.json` is the compatibility content map; do not edit it by hand.
- `src/data/sqlLearningContent.ts` is a compatibility export of the built Learning Path data, not another taxonomy.

Stable category, topic, and subtopic IDs are the integration keys. Topic Chat, SQL Practice, and SQL Practiced Notes resolve their curriculum from the same built taxonomy. Keep lesson content out of UI components.

## Course TXT format

Use one `=== LESSON ===` block per subtopic. Include the exact category, topic, and subtopic names and IDs from `taxonomy.json`. The importer accepts the headings and section layout used by the official pilot source:

```text
COURSE: SQL Course

=== LESSON ===
LESSON: Selecting Columns
CATEGORY: SQL Foundations
CATEGORY_ID: sql-foundations
TOPIC: SELECT Statements
TOPIC_ID: select-statements
SUBTOPIC: Selecting Columns
SUBTOPIC_ID: selecting-columns

Explanation:
Explain the lesson in complete paragraphs.

Examples:
SELECT employee_name
FROM employees;

Key Points:
- State an essential point.

Common Mistakes:
- Describe a likely mistake.

Interview Relevance:
State an interview-relevant concept.

Practice Guidance:
Give a concrete practice suggestion.
```

Each lesson requires all six content sections: Explanation, Examples, Key Points, Common Mistakes, Interview Relevance, and Practice Guidance. The importer maps Interview Relevance to the existing interview-points field and Practice Guidance to the existing practice-questions field.

The importer also accepts the explicit `CONTENT:` plus bracketed-section format for standalone lesson files. Both formats are validated against the canonical three-level path; neither can create taxonomy nodes.

## Validate and integrate

1. Add source TXT files to `src/data/learningPath/content/txt/`.
2. Validate and import a course:

   ```sh
   node scripts/import-learning-content.mjs --course path/to/course.txt
   ```

3. Use `--replace` only when intentionally replacing content already registered for those subtopic IDs:

   ```sh
   node scripts/import-learning-content.mjs --course --replace path/to/course.txt
   ```

4. Review the generated registry. The importer validates the full incoming course before replacing the registry and discards entries that no longer belong to the current official taxonomy.

Taxonomy edits require a separately reviewed change to `taxonomy.json` and related references. Never add a Module field or maintain a separate taxonomy in SQL Practice or SQL Practiced Notes.
